## 3. Waiver Declarations

In accordance with [docs/en/TESTING_CHECKLIST.md](file:///docs/en/TESTING_CHECKLIST.md), boundary scenarios restricted by hardware or lab infrastructure are documented and waived:

1. **Physical 4G/5G Cellular Multi-Cell Tower Handover (Dimension 3.3)**:
   - **Constraint**: Testbed operates across fixed broadband and public clouds without programmable cellular modem hardware.
   - **Compensating Controls**: Fully validated via Linux kernel `tc netem 30% loss 150ms delay 20ms` chaos injection and automated in-place `ice_restart: true` re-handshake logic.
2. **Native Apple WebKit Hardware Sandbox (Dimension 4.6.2)**:
   - **Constraint**: Current testbed topology consists of Windows 11 and Linux Debian 13; physical Apple macOS/iOS hardware running Safari 17+ was unavailable.
   - **Compensating Controls**: Validated against modern Chromium and Edge dual-engine environments executing W3C specifications (`new Response(null, {status: 204})`, Module Workers, Streams API).
3. **IPv6-Only Cellular NAT64 Environment (Dimension 3.5)**:
   - **Constraint**: Dedicated IPv6-only network with upstream DNS64/NAT64 translation was unavailable.
   - **Compensating Controls**: System maintains complete dual-stack STUN/TURN fallback cascades, verified through comprehensive unit tests.
