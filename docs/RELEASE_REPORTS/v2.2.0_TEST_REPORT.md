依据 [docs/TESTING_CHECKLIST.md](file:///docs/TESTING_CHECKLIST.md) 的发版准入规范，对于受物理硬件或外设网络条件限制无法现场施测的边界项，在此明确记录并豁免：

1. **真实多网卡物理 4G/5G 蜂窝跨基站漫游测试（维度 3.3）**：
   - **限制说明**: 本次测试处于固定宽带局域网与公网环境，缺乏带可编程移动蜂窝 SIM 模块的外置测试机进行物理基站漫游切换。
   - **替代弥补**: 已通过 Linux 内核级 `tc qdisc add dev lo root netem loss 30% delay 150ms 20ms` 极限混沌损耗注入，以及自动化 `ice_restart: true` 原位平滑重连逻辑予以全量覆盖。
2. **Apple WebKit 原生沙箱环境测试（维度 4.6.2）**：
   - **限制说明**: 现有测试机拓扑为 Windows 11 + Linux Debian 13，缺乏物理 Apple Mac / iPad 硬件运行真机 Safari 17+。
   - **替代弥补**: 已通过现代 Chromium 与 Edge 原生双核环境针对 W3C 规范级特性（`new Response(null, {status: 204})`、Module Worker、Stream API）执行严格断言。
3. **单栈纯 IPv6-only 蜂窝 NAT64 测试（维度 3.5）**：
   - **限制说明**: 缺乏仅分配 IPv6 地址且上游启用严格 DNS64/NAT64 转换的独占单栈蜂窝网络环境。
