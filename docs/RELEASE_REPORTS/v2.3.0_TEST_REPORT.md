## 四、 核心架构防护与脆弱点对抗判定

对标 [docs/REVIEW_GUIDELINES.md](file:///docs/REVIEW_GUIDELINES.md) 案例库及 v2.3 核心演进：
- **Case 1 (CookieJar 内存隔离)**: 独立远端 Session 的 SessionId 隔离，跨标签页绝无 Cookie 交叉串扰 ➡️ **PASS**
- **Case 2 (DecompressionStream Null-Body 抛错)**: 针对 HEAD 与 204/304 响应实施严格空 Body 旁路，零 `TypeError: Compressed input was truncated` 异常 ➡️ **PASS**
- **Case 3 (Durable Object WebSocket Hibernation 唤醒)**: 在真实 Cloudflare DO 上验证会话 Attachment 反序列化与状态恢复，休眠前后密钥校验与连接计数零下溢 ➡️ **PASS**
- **Case 4 (顶层域名与子域名 Node ID 提取防劫持)**: 85 项 Web 虚拟化与边界逻辑全部绿灯，保留子域名防覆盖生效 ➡️ **PASS**
- **Case 5 (纯字节流 HTML 脚本注入防乱码)**: 模拟多 Chunk 边界拆分，采用原生字节切片拼接，零 `\uFFFD` 乱码破坏 ➡️ **PASS**
- **Case 6 (Wire 协议首帧类型纯正性)**: 严格维持 `TypeHeaders` 首帧契约，零 10 秒超时死锁 ➡️ **PASS**
- **Case 7 (AgentSession 世代防误杀)**: 验证过期的 5s Teardown 定时器到达时，因检测到 `Generation` 已递增而主动忽略，成功保护新建立的 Mux 连接 ➡️ **PASS**
- **Case 8 (CAS 原子流控准入)**: 并发高频触发流创建，CAS 严格约束并发流上限，零 TOCTOU 越界 ➡️ **PASS**
- **Case 9 (双物理通道解耦与队头阻塞免疫)**: `p2pcontrol` 与 `p2pdata` 分立，控制帧发送彻底绕过数据背压，大文件传输中 Ping RTT 毫秒级即达 ➡️ **PASS**
- **Case 10 (跨信道无序与孤儿帧缓冲熔断)**: `p2pdata` 先于 `p2pcontrol` 到达的数据帧被暂存至受限池（64KB/256KB），HEADERS 抵达即时认领冲刷；500ms 无主认领自动发送 RST_STREAM 熔断回收 ➡️ **PASS**
- **Case 11 (DTLS 证书指纹联合防重放)**: `-sign-link` 生成的基础签名在使用时强制与访客 WebRTC 协商的 DTLS 证书指纹二次联合计算 HMAC，异机抓包重放拦截率 100% ➡️ **PASS**
